# ChatGPT Excel AHK 設計規格

日期：2026-10-19

## 目標

建立一個 AutoHotkey v2 單機工具，讓使用者以單鍵、逐步且人工觸發的方式完成以下流程：

1. 從 Excel 目前的問題儲存格讀取文字。
2. 將文字送到目前聚焦的 ChatGPT Chrome 頁面。
3. 複製 ChatGPT 最後一則回答。
4. 將回答寫回 Excel 的回答儲存格。
5. 成功後才把問題與回答位置一起移到下一列。

工具不使用滑鼠座標、不自動輪詢、不自動連續送出，也不自動關閉瀏覽器。

## 執行環境與相依性

- Windows
- AutoHotkey v2
- Microsoft Excel 桌面版（透過 COM 控制）
- Google Chrome
- ChatGPT 網頁

## 啟動流程

1. 顯示檔案選擇器，讓使用者選擇既有 Excel 活頁簿。
2. 使用 Excel 開啟該活頁簿並顯示視窗。
3. 呼叫 Excel 原生範圍選擇器，要求使用者點選一個「問題起始格」。
4. 再次呼叫範圍選擇器，要求使用者點選一個「回答起始格」。
5. 兩個範圍都必須是單一儲存格；取消或選到多格時停止啟動並提示原因。
6. 顯示：`準備完成｜問題 工作表!A2 → 回答 工作表!B2`。

問題格與回答格可以位於不同工作表，但必須屬於同一本活頁簿。

## 快捷鍵

| 按鍵 | 行為 |
|---|---|
| `F1` | 啟用或暫停動作鍵。暫停時 `Z/X/C/V/A` 不攔截原按鍵。 |
| `F2` | 結束腳本。先釋放 Excel COM 物件，再短暫顯示結束訊息。 |
| `Z` | 開啟新的 Chrome 無痕視窗並前往 `https://chatgpt.com/`。 |
| `X` | 從目前問題格讀值，對目前聚焦的 Chrome 依序送出 `Shift+Esc`、貼上及 `Enter`。 |
| `C` | 對目前聚焦的 Chrome 送出 `Ctrl+Shift+C`，確認剪貼簿更新後，寫入目前回答格並儲存活頁簿。 |
| `V` | 清除目前保留中的警告。 |
| `A` | 關閉目前聚焦的整個 Chrome 視窗。 |

`F1` 與 `F2` 永遠有效。其他動作鍵只在啟用狀態有效。

## 動作規則

### Z：開啟 ChatGPT

- 依序尋找 Chrome 可執行檔：系統 App Paths、Program Files、Program Files (x86)、Local AppData。
- 使用 `--incognito --new-window https://chatgpt.com/`。
- 開啟成功後讀取目前問題格，在滑鼠旁顯示待貼入預覽；預覽最多 120 個字、最多四行，超過時以 `…` 結尾。
- 預覽保留至按下 `X` 成功送出、出現警告或執行其他會改變工作狀態的動作。
- 目前問題格為空白時仍開啟 ChatGPT，但改為顯示持續警告，不顯示空白預覽。
- 找不到 Chrome 或啟動失敗時顯示持續警告。

### X：送出問題

- 必須由 Chrome 視窗取得焦點；否則停止並顯示警告。
- 讀取目前問題格的顯示文字；空白時停止。
- 把問題文字放入 Windows 剪貼簿。
- 送出 `Shift+Esc` 聚焦 ChatGPT 輸入框，再送出 `Ctrl+V` 與 `Enter`。
- 成功後只記錄「已送出」狀態，不移動 Excel 列號。

### C：複製並儲存回答

- 必須由 Chrome 視窗取得焦點；否則停止並顯示警告。
- 先清空剪貼簿，再送出 `Ctrl+Shift+C`。
- 在限定時間內等待非空剪貼簿；逾時即視為複製失敗。
- 複製成功後先將目前回答格設為文字格式，再寫入純文字並呼叫活頁簿儲存；以 `=` 開頭的回答不得被 Excel 當成公式執行。
- 只有「寫入」與「儲存」都成功後，問題格和回答格才各自往下一列。
- 任一步驟失敗都不移動位置，可直接再次按 `C` 重試。

### A：關閉視窗

- 只有目前聚焦程序是 Chrome 時才送出 `Alt+F4`。
- 此動作關閉整個目前 Chrome 視窗，不與 `C` 綁定。
- 若目前不是 Chrome，顯示警告且不送出按鍵。

## 滑鼠旁提示

使用一個無標題列、永遠置頂且不取得焦點的小型 GUI，定時跟隨滑鼠位置。成功訊息約 2.5 秒後消失；警告持續顯示直到按 `V`，且新的成功訊息不能蓋掉尚未確認的警告。

| 情況 | 顯示文字 |
|---|---|
| 啟動完成 | `準備完成｜問題 工作表!A2 → 回答 工作表!B2` |
| 開啟成功 | `待貼入｜工作表!A2`，下一行起顯示最多 120 字、四行的問題預覽 |
| 送出成功 | `已送出問題 工作表!A2｜等待回答` |
| 問題空白 | `送出失敗｜工作表!A2 沒有內容` |
| 視窗錯誤 | `操作失敗｜請先對焦 ChatGPT 頁面` |
| 寫入成功 | `已儲存回答 工作表!B2｜下一題 工作表!A3` |
| 複製失敗 | `複製失敗｜按 V 清除後，再按 C 重試` |
| 寫入失敗 | `寫入失敗｜工作表!B2 未寫入、位置沒有移動` |
| 儲存失敗 | `儲存失敗｜位置沒有移動，請按 C 重試` |
| 關閉成功 | `已關閉目前的 Chrome 視窗` |
| 暫停 | `快捷鍵已暫停｜按 F1 恢復` |
| 恢復 | `快捷鍵已恢復｜目前問題 工作表!A2` |
| 結束 | `AHK 已結束` |

成功為綠色、一般提醒為黃色、失敗為紅色。

## 狀態與資料所有權

AHK 腳本是唯一狀態擁有者，保存：

- 啟用／暫停狀態
- 活頁簿與 Excel COM 參考
- 問題起始 Range、回答起始 Range
- 已成功完成的列偏移量
- 目前提示內容、類型及到期時間
- 是否存在尚未確認的警告

Excel 活頁簿是問題與回答的永久資料來源。列偏移量不另外寫入設定檔；每次重啟都重新選擇起始格。

## 失敗與安全行為

- 不對非 Chrome 前景視窗送出 ChatGPT 或關閉快捷鍵。
- 不因送出問題而移動列號。
- 不因只複製成功而移動列號。
- Excel 儲存成功才移動列號。
- 不覆蓋尚未確認的紅色警告。
- 紅色警告存在時，`Z/X/C/A` 不執行動作；使用者必須先按 `V` 表示已閱讀。
- 結束腳本不強制關閉 Excel，使用者仍可查看活頁簿。
- `Ctrl+Shift+C` 若因 ChatGPT 版本或帳號差異失效，只顯示警告，不使用滑鼠或 DOM 備援。

## 交付檔案

- `ChatGPT_Excel_助手.ahk`：主程式。
- `AHK功能測試.xlsx`：含問題欄、回答欄及數筆無害測試問題。
- `測試清單.md`：一頁式按鍵驗收流程與預期提示。
- 本設計規格。
- 實施計畫。

## 驗收條件

1. 啟動時可以圖形化選擇活頁簿、問題格和回答格。
2. `F1` 暫停後，`Z/X/C/V/A` 恢復為一般字母鍵。
3. `Z` 開啟成功後會顯示目前問題格的待貼預覽，且長內容不超過 120 字與四行。
4. `X` 只在 Chrome 聚焦且問題非空時送出。
5. `C` 失敗時不寫入、不儲存、不移動列號；成功時寫入、儲存並移到下一列。
6. 紅色警告會跟隨滑鼠並保留至 `V`。
7. `A` 只關閉目前聚焦的 Chrome 視窗。
8. `F2` 結束腳本但保留 Excel 視窗。
9. 使用測試活頁簿可完成至少兩輪問題與回答寫入。

## 已接受的取捨

- 以 ChatGPT 現有鍵盤快捷鍵換取不使用滑鼠座標；網站改版可能使快捷鍵失效。
- 只檢查前景程序為 Chrome，不讀取網址；使用者必須自行確認目前頁面是 ChatGPT。
- 使用 Excel COM 可提供原生選格與可靠儲存，但要求安装桌面版 Excel。
- 不加入自動等待回答完成、批次迴圈、網頁內容解析或自動重試，以維持人工控制和較低風險。
